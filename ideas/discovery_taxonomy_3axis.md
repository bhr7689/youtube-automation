## 3️⃣ 조합 검색 엔진 설계 (칩 → 검색어 자동 생성)

### UX 흐름
```
[🎵 장르 칩들]  [🕒 상황 칩들]  [💗 감정 칩들]     ← 각 축 0~2개 선택 (전부 선택 안 해도 됨)
        ▼ "🎲 조합 검색" 버튼
시스템이 검색어 6~12개 자동 생성 → 칩으로 표시 (사용자가 X로 빼거나 수정 가능)
        ▼
각 검색어로 YouTube API 검색 → 결과 합치고 중복 제거
        ▼
카드 그리드 (기존 검색 화면과 동일 UX: 배수·⭐·➕·📁)
```

### 검색어 생성 템플릿 (예)
```
[감정 문구] + [장르]                     → "듣다가 울어버린 트로트"
[상황 문구] + 듣는 + [장르]              → "잠 안 올 때 듣는 뉴에이지"
[장르] + [서픽스]                        → "재즈 플레이리스트 3시간"
[감정 문구] + [상황 문구] + [서픽스]      → "마음이 편안해지는 비 오는 날 BGM"
[영어 조합]                              → "rainy day jazz playlist"
[일본어 조합]                            → "作業用BGM ジャズ 3時間"
```

### 예시: `트로트 × 수면·휴식 × 슬픔·그리움` 선택 시
- 듣다가 결국 울어버린 트로트 메들리
- 가슴 시린 옛날 트로트 모음
- 잠 안 올 때 듣는 애절한 트로트
- 사무치게 그리운 7080 트로트 연속듣기
- 부모님 세대 눈물 트로트 1시간
- 懐メロ 演歌 メドレー (일본어 확장 시)

### 📒 검색 레시피 (조합 저장·자동 재실행)
- 마음에 든 조합을 **레시피로 저장** (K-Trot `recipes.py` 개념 재사용)
- 저장된 레시피는 **트렌드 피드가 매일 자동 재실행** → 새로 뜬 채널·영상만 🔔 알림
- 즉: 한 번 조합을 잘 만들어두면 → 매일 아침 "이 취향의 신상"이 자동 배달

## 5️⃣ 발굴 → 저장 자산 흐름 (북마크·레퍼런스·컬렉션)

```
🎲 조합 검색 결과 카드
 ├─ ⭐ 북마크        → 빠른 임시 저장 (전 화면 공유, 북마크 패널에 통합)
 ├─ ➕ 레퍼런스 등록  → 채널을 추적 대상으로 (배수 계산 시작, 트렌드 피드 감시)
 └─ 📁 컬렉션 담기    → 장르별/카테고리별 폴더에 정리 (영구 자산)
```

### 📁 컬렉션 설계
- 폴더 = 자유 생성 (예: "트로트 눈물 플리", "일본 감동 소스", "카페 재즈 벤치마크")
- 폴더 안 항목: 채널/영상 + 사용자 메모 + 담긴 날짜 + 어떤 조합(레시피)에서 발견됐는지
- **파일 내보내기**: 폴더 단위 CSV / JSON / Markdown 다운로드
  (→ 나중에 Notion 적재, 번역봇·컷편집 입력으로도 연결)
- 컬렉션 항목에서 바로: 🌸 번역봇으로 보내기 / ✂️ 컷편집으로 보내기 (도구 간 연결)

## 6️⃣ 왜 이 구조가 강한가 (Claude 의견)

1. **"검색을 몰라도 된다"를 진짜로 해결** — 사용자는 칩 3개만 고름. 하얀 검색창 공포 제거.
2. **어휘 = 복리 자산** — 좋은 문구를 축에 추가할수록 모든 조합이 강해짐 (vocab.json 철학).
3. **레시피 저장 → 매일 자동 재실행** — 발굴이 일회성 행위가 아니라 구독형 피드가 됨.
4. **다국어 어휘 내장** — 일본 시니어 프로젝트(作業用BGM, 泣ける, 懐メロ)와 자연 연결.
5. **카테고리 복제 가능** — 음악에서 검증한 틀을 감동·예능·지식으로 확장. 앱이 커져도 구조는 하나.
6. **기존 자산 재사용** — 배수 계산(title_analyzer), 레시피(recipes.py), 통제어휘(vocab.json),
   시드+사용자편집 보존(nation_prompts.py) 패턴 전부 이식 가능.
