# 🕵️ 쇼츠헌터 — 원본 추적(Source Trace) 화면 기획서

> 작성: 2026-08-01 (claude/elements-tools-planning-list-yqqo2t)
> 사장님 지시 요약:
> - 영상 링크를 주거나 **새로 올라오는 영상을 자동 체크**하면
> - **같은 배경·소재**를 쓴 영상들을 **업로드 날짜순으로 배열**하고
> - 🌍 **외국어**로 제목이 만들어진 영상 중 **최초·두번째로 쇼츠화한 영상**을 찾고
> - 🇰🇷 **한국어**로 만든 **첫번째·두번째 영상**도 찾되,
>   한국은 **"내가 하려는 카테고리의 대장(1인자) 채널"을 찾아 분석**하는 것이 목적
> - 그 영상들의 **채널까지 찾아 🔖 북마크**할 수 있게

---

## 1. 화면 한 줄 정의

**하나의 바이럴 소재가 "언제·누가·어느 나라에서" 퍼졌는지 확산 타임라인을 그려주고,
🌍 원조(외국어 1·2번째)와 🇰🇷 국내 대장 채널을 집어 🔖 저장·분석까지 연결하는 화면.**

기존 `source_finder`(원본 소스 역추적)를 **"단일 원본 판정" → "확산 타임라인 + 버킷 분리 + 채널 저장"** 으로 확장한 것.

---

## 2. 입력 (진입점 2가지)

1. **링크 직접 입력** — 쇼츠 URL 한 줄 붙여넣기
2. **새 영상 자동 체크** — 급등 피드(`global_surge`)/저장 채널(`channel_watcher` RSS)에서
   새로 뜬 영상을 자동으로 이 추적에 흘려보냄 (토글 ON 시 무인)

---

## 3. 파이프라인 (알고리즘)

```
[URL/새영상]
  └─ ① 소재 지문 추출        (source_finder 재사용)
        · 메타(제목·업로드일·채널)  · yt-dlp 다운로드(480p)
        · 대표 프레임 N장 + contact_sheet  · 워터마크 @핸들 OCR
  └─ ② 동일 소재 후보 수집     (여러 신호 병합 — best-effort)
        a) 프레임 역이미지 검색(Google/Bing/Yandex/DDG) → 같은 클립 사용 영상
        b) 제목 핵심어 다국어 교차검색(translate_query + youtube search) — 언어별
        c) 워터마크 @핸들 → 원 채널 직행
        d) (선택) 오디오 지문 → 같은 원음/BGM
  └─ ③ 후보 videos.list → publishedAt 확보 → 오름차순 정렬
        = 📅 확산 타임라인
  └─ ④ 버킷 분리
        🌍 외국어(제목 언어감지, ko 아님) → 최이른 2개 = 🥇원조 🥈2번째
        🇰🇷 한국어(제목 ko)          → 최이른 2개 + 대장 채널 산정
  └─ ⑤ 채널 해석 → 🔖 북마크 → 저장채널/알림 연결
        · 한국 대장 채널 → 채널 분석 진입(collect_channel/tier_lab/Vision)
```

### 🇰🇷 "대장 채널" 산정 방식 (한국 버킷 전용)
같은 소재/카테고리의 한국 후보 채널들을 다음 지표로 랭킹해 1인자 선정:
- 구독자수, 평균 조회수, 조회수 배수(조회수÷구독/채널평균)
- 업로드 주기(꾸준함), 최근 90일 누적 조회, 카테고리 적중도
→ 상위 = **대장 채널**. 여기에 채널 분석(제목공식·썸네일 패턴·업로드 리듬) 부착.

---

## 4. 화면 레이아웃 (위 → 아래)

1. **입력 바** — URL 입력 + [🔍 추적 시작] + [🔔 새 영상 자동 체크] 토글
2. **소재 지문 패널** — 대표 프레임 썸네일 + 감지된 @핸들 + 원본 롱폼 후보
3. **📅 확산 타임라인** — 날짜 가로축, 외국어=파랑 / 한국어=빨강 점, 최초에 🥇 배지
4. **🌍 외국어 원조 (2장)** — 🥇1st / 🥈2nd 카드: 썸네일·제목·**업로드일**·채널·[🔖]
5. **🇰🇷 한국 대장 채널 (분석 카드)** — 채널명·구독·평균조회·배수·업로드주기·제목공식·
   썸네일 패턴 + [🔖 저장] [🔬 심층분석] + 그 채널의 🥇1st / 🥈2nd 한국 쇼츠
6. **🔖 저장한 채널** — 이 추적에서 북마크한 채널들 (→ 저장채널 탭·알림으로 이어짐)

## 5. 기존 자산 매핑 (재사용 vs 신규)

| 단계 | 기존 코드 | 판정 |
|---|---|---|
| 메타·다운로드·프레임·핸들 OCR | `source_finder.py` (stage_meta/download/frames/handles) | ✅ 재사용 |
| 역이미지·5플랫폼 후보 | `source_finder.stage_candidates` (DDG·프로필 probe) | ✅ 재사용 |
| 다국어 제목 교차검색 | `youtube_client.translate_query` + search | ✅ 재사용 |
| 채널 북마크 · 알림 | `viral_channels.py` · `genre_store.py` · `channel_watcher.py` · `kakao_notify.py` | ✅ 재사용 |
| 한국 대장 채널 분석 | `concept_maker.collect_channel` · `tier_lab.py` · Vision | ✅ 재사용 |
| **확산 타임라인 정렬 + 외/한 버킷 1·2위 산정** | — | 🆕 신규 로직(source_finder에 stage 추가) |
| **한국 "대장 채널" 랭킹 산정** | — | 🆕 신규 로직 |
| **source_trace.html 화면** | — | 🆕 신규 화면 |

→ **로직의 70~80%는 이미 있고, "타임라인·버킷·대장채널 산정 + 화면"만 신규.**

## 6. 정직한 한계 (설계 전제)

- YouTube API에는 **"영상 시각 유사 검색"이 없다.** 동일 소재 매칭은
  [역이미지 + 다국어 제목검색 + 워터마크 핸들 + (선택)오디오지문]의 **조합 best-effort**다.
  100% 자동 완벽 매칭은 불가 → **후보 랭킹 + 사람 확인** 구조로 간다.
- 웹 컨테이너는 프록시가 유튜브를 차단 → 실동작은 **사장님 PC(yt-dlp/ffmpeg/API키)** 에서.
- "최초"는 수집된 후보 범위 내 최이른 공개일 기준(전수 크롤 불가) → **"관측된 최초"** 로 표기.

---

## 7. 백엔드 API (신규, 붙일 자리)

- `POST /api/source-trace` — {url, auto} → job 시작(기존 source_finder 잡 재사용 + 버킷 stage)
- `GET  /api/source-trace/{job}` — 진행/결과(타임라인·외국어2·한국대장·한국2)
- `POST /api/channels`(기존) — 🔖 북마크 저장 (viral_channels/genre_store 재사용)
- 한국 대장 분석은 기존 `/api/concept/*`·채널분석 엔드포인트 재사용
