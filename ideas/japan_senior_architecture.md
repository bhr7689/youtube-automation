## 🧩 3개 도구 (포털 구조)

```
┌──────────────────────────────────────────────────────────┐
│           🏠 포털 메인 (Google OAuth 로그인)               │
│         "일본쇼츠 자동 프로그램" · 쇼치 강사 시리즈         │
└───────────┬──────────────┬──────────────┬────────────────┘
            ▼              ▼              ▼
     📺 RefTracker    🌸 번역봇       ✂️ 자동 컷편집
     레퍼런스 추적    JP 변환+TTS     대본 맞춤 컷
```

| 도구 | 역할 | 입력 → 출력 | 우선순위 |
|---|---|---|---|
| 📺 **RefTracker** | 채널 등록·트렌딩·검색·컬렉션 | 키워드/채널 → 유망 쇼츠 큐 | 🥇 1순위 (오늘) |

| ✂️ **자동 컷편집** | 롱폼 + JP대본 → 자동 컷 | 영상 + 대본 → 쇼츠 MP4 | 🥉 3순위 |

## 📊 데이터 정확도 원칙 ⭐ (가장 중요)

### ✅ 100% 정확 (YouTube Data API v3 공식)
조회수 · 좋아요 · 댓글수 · 구독자수 · 업로드시각 · 영상길이 · 제목/설명/썸네일 · 태그(대부분)

### 🟢 우리가 직접 계산 = 정확
- **배수(multiplier)** = 영상 조회수 ÷ 채널 최근 평균 조회수 (시안 ×38.1 방식)
- **구독자 대비 배수** = 영상 조회수 ÷ 구독자수 (병기)
- **VPH** = 조회수 ÷ 업로드 후 경과시간
- **참여율** = (좋아요+댓글) ÷ 조회수

### 🟠 추정치 — "추정" 라벨 필수 (아무도 정확히 못 줌, vidIQ도 추정)
- 키워드 월 검색량 → **A안 채택**: YouTube 자동완성 + 검색결과 수로 근사, "추정" 배지
- 경쟁 강도 → 상위 결과의 채널 규모 분산으로 근사, "추정" 배지
- ❌ SEO 점수·예상 수익 = 넣지 않음 (근거 약함)

## 🖥️ RefTracker — 화면 명세 (시안 3장 기준)

### 사이드바 (좌측)
- 브랜드: **RefTracker** / "레퍼런스 채널 추적"
- 메뉴: 🔥 트렌드 피드 · 🌐 YouTube 발굴 · 🔍 **검색** · 📺 레퍼런스 채널 · 📁 컬렉션 · ⭐ 북마크 · 🔔 알림 · ⚙️ 설정
- 하단 점프: 🏠 포털 메인 · 🌸 일본어 번역봇 · ✂️ 자동 컷편집
- 로그인: Google 아바타 + 이메일 + 로그아웃 · 버전

### 🔍 검색 화면 (오늘 구현)
1. **키워드 검색바** + Enter → 검색 · 최근검색 chip (형식아이콘+기간, ✕ 제거, 전체 지우기)
2. **영상 / 채널** 탭
3. **검색 옵션** (변경 시 새로 가져옴 = API 호출):
   - 범위: 🌐 유튜브 전체 / ⭐ 내 레퍼런스 채널만
   - 기간: 1일·3일·1주·1달·3달·6달·1년·전체
   - 기준: 🔥 인기 영상 / 🆕 최신 영상
   - 형식: 📱 Shorts / 🎬 롱폼 / 전체
   - 개수: 100·200·300·500
   - 언어: 9개국 체크박스 (한/영/일/중/스페인/독/프/포르투갈/힌디)
4. **결과 내 정렬·필터** (즉시 적용 = API 호출 안 함):
   - 정렬: 조회수 / 🔥급등 배수 / 🆕최신 / 원본 순서
   - 배수: 전체·×1↑(평균↑)·×2·×3·×5·×10·×30
   - 조회수: 전체·10만·50만·100만·500만·1000만 ↑
5. **결과 카드** (그리드):
   - SHORTS/롱폼 배지 + 영상길이 + ⭐북마크
   - 썸네일 · 제목 · 채널명 · 조회수 · N일 전
   - **배수 배지** (×38.1) — 등록 채널 영상은 강조
   - **+ 추가**(미등록) / **✓ 등록**(등록됨) 버튼
   - 액션: 📜자막 · ✏️원본 · 📰유사 · 💬댓글 · 🔗링크

### 왜 FastAPI + Tailwind 단일 페이지인가 (스택 결정)
- **오늘 시현 + `.bat` 더블클릭 실행 + 시안 디자인 재현** 3개를 동시 만족
- Next.js는 node/npm 빌드가 비개발자에게 무거움 → 나중에 규모 커지면 이관
- Python이라 기존 YouTube API 코드(collect.py) 패턴 재활용
- 키 없으면 mock 데이터로 화면 시현 가능 → 키 넣으면 즉시 실데이터

## 🔌 API 설계 (백엔드)

| 엔드포인트 | 메서드 | 역할 | 정확도 |
|---|---|---|---|
| `/api/search` | GET | 키워드+옵션 → 영상 리스트 + 배수 | 🟢 실데이터 |
| `/api/channels` | GET/POST/DELETE | 등록 레퍼런스 채널 관리 | 🟢 |
| `/api/bookmarks` | GET/POST/DELETE | 북마크 | 🟢 |
| `/api/collections` | GET/POST | 컬렉션 | 🟢 |
| `/api/transcript/{id}` | GET | 자막 (📜자막 버튼) | 🟢 |
| `/api/keyword-estimate` | GET | 검색량 **추정** | 🟠 추정 라벨 |
| `/api/health` | GET | 키 유무·상태 | — |

### 배수 계산 로직 (정확)
```
채널 평균 = 그 채널 최근 영상 N개(기본 15)의 중앙값 조회수  # 이상치에 강한 중앙값
배수 = round(영상 조회수 / 채널 평균, 1)
등록 채널이면 → 캐시된 평균으로 즉시 계산
미등록 채널이면 → 검색 시 채널 통계 1회 조회 후 계산 (쿼터 절약: 채널당 1회)
```
