📚 카테고리별 학습 관리
카테고리마다 코퍼스가 따로 쌓이고, 수집이 끝나면 자동 재학습됩니다 (섞임 없음)
확인 중…
🔄 학습 원리 — 수집(터진 쇼츠 대본·태그·댓글) → 훅 유형·구조·키워드 통계 자동 갱신 → 대본·제목 생성이 그 카테고리 규칙만 사용. 목표 500편, 100편부터 규칙이 안정화됩니다.
🌏 밖에서도 쓰기 (외부 접속)
외출 중 폰으로 작업한 것도 사무실 데스크톱에 그대로 저장돼요 — 폰이 밖에서도 이 서버에 연결되기만 하면 됩니다. 무료·안전·주소 안 바뀌는 Tailscale 방식을 권장해요.
확인 중…
🔧 Tailscale 설치 (10분, 한 번만)
1. 서버 데스크톱: tailscale.com/download 에서 설치 → 구글 계정으로 로그인
2. 폰: 앱스토어/플레이스토어에서 Tailscale 설치 → 같은 계정으로 로그인
3. 둘 다 로그인하면 끝 — 이 화면에 🌏 어디서나 주소(100.x.x.x)가 자동으로 떠요
4. 폰에서 그 주소로 열고 홈 화면에 추가 → 이제 사무실·밖 어디서나 같은 아이콘으로 접속
※ 공유기 설정·포트 개방 불필요. 데이터는 계속 사무실 PC 한 곳에만 쌓여요.
💾 데이터 보관
학습 자산이 어디에 쌓이는지
· 코퍼스·규칙·기록: jpshorts/backend/data/ (실행하는 PC에 영구 누적)
· 카테고리별 규칙: data/hook_rules/{카테고리}.json
· 내레이션 패키지: data/narration_jobs/ · 컷 플랜: data/cut_plans/
· git 에는 올라가지 않아요(개인 자산) — PC 백업 시 data/ 폴더만 복사하면 됩니다.
